Certification Overview
This certification involved designing and implementing secure AWS identity and access management solutions through a real-world, scenario-based learning experience. I reviewed a fictional customer case and designed an AWS solution that followed security best practices and compliance requirements.
I compared IAM users, roles, and groups, analyzed the structure and components of IAM policies, and applied least-privilege access principles. I also explained and applied the AWS Shared Responsibility Model while gaining awareness of AWS compliance programs.
After completing the design, I implemented the solution in a live AWS Management Console using guided labs. This included hands-on work with AWS Identity and Access Management, Amazon EC2, and Amazon RDS, allowing me to develop practical, job-ready cloud security and access management skills.
